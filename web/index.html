    划词行为

    设置划词触发方式、工具栏技能与默认目标语言。

    启用划词工具

    关闭后拖选文本不再弹出工具栏

    紧凑模式

    工具栏只显示图标，不显示文字

    面板模式

    滚动：面板高度固定，内容在面板内滚动，窗口不随内容变大；自适应：面板无滚动条，窗口随内容自动变高

    工具栏技能

    勾选要显示在工具栏的技能，拖动调整顺序；两个分类分别保存开关与顺序

    截图工具条

    截图后显示在工具条上的动作；拖动调整顺序

        图标
        sparkles

        没有匹配的图标，换个关键词试试

        技能类型

        文本技能处理选中文字：点击后直接执行提示词。

        支持变量：{text} 选中文本、{target} / {language} 目标语言、{program} / {app} 当前应用

        「自动识别」按原文判断：中文译为英文，其他语言译为中文

        这些应用中不触发划词；输入进程名后回车添加，可含 .exe

        快捷键

        配置 Lexora 的全局快捷键。

        截图快捷键

        点击后按下新的组合键即可修改；需包含至少一个修饰键（Ctrl / Alt / Shift / Win）

        应用与启动

        控制开机自启、托盘驻留与本地数据目录。

        开机自启

        登录 Windows 后在托盘中静默启动

        关闭窗口后驻留托盘

        关闭设置窗口时继续在托盘后台运行，划词保持可用

        数据与目录

        设置、模型、引擎与日志都保存在本机

        恢复默认设置

        重置所有选项（不删除自定义技能、已下载的模型与引擎）

        退出 Lexora

        退出后划词与托盘后台全部停止
