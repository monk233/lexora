# Lexora v0.4.0 发布说明

发布日期：2026-10-28
构建：`Lexora-0.4.0-win-x64.exe`（Windows 10/11 x64，免安装单文件）

## 主要变更

### 1. Qwen3.5 统一本地 AI

- 内置 Qwen3.5 0.8B / 2B / 4B，每种提供 Q4_K_M、Q3_K_M，共六种选择。模型及对应 mmproj-F16 视觉投影器从 ModelScope 下载。
- 翻译、通用文本与视觉理解共用手动选择的模型，不再区分翻译模型与通用模型。硬件检测仅提供保守推荐标签及理由，不自动选模，也不保证特定设备上的运行速度。
- 模型管理支持删除残留模型文件，运行中的本地引擎支持重启；切换模型后需重启引擎。

### 2. 动态追问与多轮对话

- 所有 AI 文字/图片技能由模型根据内容生成最多 3 条追问建议，每轮成功回答后刷新，支持原文、初始回答与多轮历史上下文。
- 主回答收到首个非空 chunk 后预取建议；回答完成时立即展示已有结果，否则最多等待 3000 ms，超时取消并丢弃迟到结果，不使用固定建议兜底。
- 3 秒是展示等待截止，不是模型实机生成耗时或 P95 承诺。建议生成使用独立精简预算；本地未选模型或安装不完整时静默隐藏建议与追问入口。

### 3. 面板与截图交互

- 自适应面板固定宽度 `360px`，高度随内容增长并限制在屏幕可用高度内（最多 `760px`）；超过上限后隐藏滚动条，自动跟随输出，手动向上滚动时暂停跟随。合并尺寸更新并在流式期间只增高，修复长内容闪动与抖动。
- 未 Pin 面板在外部鼠标按下时立即隐藏，新划词也会隐藏；已 Pin 面板在新划词时保留，点击需要展开结果的技能才替换旧面板。
- 改进小窗口吸附，点击吸附窗口即可选中，吸附区域高亮与手动框选一致。
- 统一长截图图标，修复跨屏回到单屏后标注工具提示残留；箭头头部与尾部无缝连接，消除白色细线。

### 4. 更新、日志与默认设置

- 启动后自动检查新版本，每 6 小时复查；发现更新时弹出带 Lexora 应用身份的原生 Windows 系统通知，按版本去重。关于页支持 Markdown 发布说明。
- 新增模型调用日志 `logs/model.log`，记录输入规模、耗时与调用结果等元数据，不记录提示词或回答正文。`main.log`、`model.log`、`llama.log` 按 10MB 轮转，各保留当前文件与一个最近历史分卷，旧分卷自动清理。
- 新配置默认启用划词工具、紧凑模式、自适应面板、开机自启与驻留托盘；默认关闭文字技能中的截图、润色，以及图片技能中的序号、长截图。可在设置中重新启用。

## 升级说明

- 设置自动迁移到 schema v7。已有用户技能选择保留；新默认开关用于新配置。
- 旧 Hy-MT2 文件保留，不会自动删除；不再使用时需在“其他本地模型”中手动删除以释放磁盘空间。
- 旧 Qwen2.5 / Qwen2.5-VL 不再内置，已有文件同样保留并支持删除，不再参与内置选模。
- 升级后需下载所需 Qwen3.5 及对应视觉投影器，并手动选择模型。旧配置的模型选择迁移为空，不会自动选择其他已安装模型；选好后启动或重启本地引擎。
- 在线 API 配置与 exe 同级 `data/` 目录保留。替换 exe 前退出旧进程，将新 exe 放入原可写目录，继续使用原有数据。

## 已知限制

- 发布物仅为便携 exe，不内嵌模型、llama.cpp 引擎或 WebView2 Runtime；本地 AI 需另行下载模型及引擎，系统需具备 WebView2 Runtime。
- 图片理解需支持视觉的在线模型，或已完整安装对应投影器的本地 Qwen3.5。
- 跨屏选区暂不支持标注与长截图；返回单屏后恢复对应工具。
- 截图和长截图受 Windows UIPI 与目标应用滚动行为限制；管理员窗口、动画、固定悬浮层和特殊滚动容器可能影响抓取或拼接。
- 系统通知是否显示受 Windows 通知权限及勿扰设置影响；更新检查和下载依赖网络。

## 安装与验证

1. 下载 `Lexora-0.4.0-win-x64.exe`，放到可写目录，双击运行；应用静默启动并驻留系统托盘。
2. 从托盘打开设置，确认在线模型配置，或安装本地引擎、Qwen3.5 和对应投影器后手动选模并启动。
3. 分别验证划词翻译、图片理解、多轮追问与长文本显示；确认未 Pin 面板外部按下即隐藏、Pin 后保留。
4. 检查关于页 Markdown 发布说明、模型管理操作，以及 exe 同级 `data/` 中的日志；构建与测试结果以本次实际发布验证记录为准。
