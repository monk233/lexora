# Lexora v0.4.1 发布说明

发布日期：2026-10-28
构建：`Lexora-0.4.1-win-x64.exe`（Windows 10/11 x64，免安装单文件）

## 主要变更

### 1. 首次启动热修复（hotfix）

- 修复 v0.4.0 在全新目录首次启动时，设置窗口在 `AppState` 通过 `manage()` 注册前调用 `get_state`，出现 `state not managed`、无法读取设置的问题。
- 将状态注册提前到窗口创建之前；首次设置读取遇到该初始化错误时进行短暂重试。
- 初始化设置持久化延后到单实例确认之后，避免并发实例写入 `settings.json`；持久化失败时记录警告日志。

## 升级说明

- v0.4.1 是针对 v0.4.0 首次启动问题的热修复版本，建议 v0.4.0 用户升级。
- 退出旧进程，将 `Lexora-0.4.1-win-x64.exe` 放入原可写目录，继续使用 exe 同级的原有 `data/` 目录；已有设置、模型和在线 API 配置可继续使用。
- 首次使用时，将 exe 放到全新可写目录运行。应用初始化设置后驻留系统托盘，可从托盘打开设置。
- v0.4.0 的功能与模型迁移说明见 [v0.4.0 发布说明](release-notes-0.4.0.md)。

## 已知限制

- 发布物仅为便携 exe，不内嵌模型、llama.cpp 引擎或 WebView2 Runtime；本地 AI 需另行下载模型及引擎，系统需具备 WebView2 Runtime。
- 目录或配置写入失败会记录日志；请使用具有写入权限的目录。

## 安装与验证

1. 下载 `Lexora-0.4.1-win-x64.exe`，放到可写目录，双击运行。
2. 从托盘打开设置，确认全新目录首次启动时不再出现 `state not managed`，设置能够正常读取、保存。
3. 退出并再次启动，确认设置保持正常；需要排查时查看数据目录中的日志。
4. 构建与测试结果以本次实际发布验证记录为准。
