# R2 P3 Picker 窗口重写 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 React 重写 `picker` 与 `picker-toolbar` 两个表面（划词工具条胶囊 + 结果面板），行为对齐 `docs/contracts.md` §6.2/§6.3/§7.1 与旧实现 `web/picker.js`，使 `frontend/dist/picker.html` 取代 `web/picker.html`。

**Architecture:** 单入口 `frontend/src/entries/picker.tsx` 按 `?surface=toolbar` 分派到 `PickerToolbar`（胶囊）或 `PickerPanel`（结果面板）。窗口尺寸/位置/拖拽仍由 Rust 负责，React 只上报所需尺寸（`picker_resize`、`picker_drag_panel`）；流式使用已迁移的 `useStream` + `stream-guard` + `markdown`，但 `useStream` 的 `abort` 语义先按 `contracts.md:400` 修正（停止保留已输出内容）。

**Tech Stack:** React 18.3、TypeScript 5、Tailwind 3.4、shadcn/ui 源码、lucide-react、`@/lib/tauri-api.js`（pickerAPI）、`@/hooks/useStream`、`@/lib/stream-guard`、`@/lib/markdown`。

## Global Constraints

- **不改 Rust**：`src-tauri/**` 零改动；窗口尺寸/位置/拖拽/隐藏全部仍由 Rust 执行，React 只发命令。
- **不改 IPC 契约**：命令与事件名保持 `picker_ready / picker_data / picker-image / translate-event / picker-hidden` 等原样；`pickerAPI` 方法名不改。
- **非激活窗口语义**：picker 窗口 `focusable:false`；React 不得调用 `set_focus` 之类；外部点击/键盘/滚轮的隐藏判定在 Rust，React 只处理面板内交互。
- **透明窗 + 阴影**：窗口背景透明；胶囊与面板各自是白卡片，阴影由 CSS 提供，不得给 `body` 加不透明背景。
- **两个表面共用入口**：`picker.html` 同时服务 `picker` 与 `picker-toolbar`，靠 `?surface=toolbar` 区分；面板已固定时新划词走 toolbar 表面。
- **尺寸**：工具栏宽度上限普通 560px / compact 420px，超出技能进「更多」菜单；面板最小 360×240；auto 模式宽 360、高度随内容 `min(可用高-80, 760)`，resize 合并 ≤100ms 且流式期间只增不减；scroll 模式固定窗口、可拖拽缩放、尺寸存 `localStorage.lexora.panelSize`。
- **停止语义以 `docs/contracts.md:400` 为准**：点击停止 → 标记终止 → `picker_abort_translate` → **已输出内容保留**并追加「已停止生成」→ 后续 chunk/error/done 一律忽略 → 重试入口保留。
- **流式渲染**：Markdown 安全子集（HTML 先转义、仅 http(s) 链接、链接走 `open_external`）；chunk 用 rAF 合并；用户上滚时暂停自动滚动，接近底部恢复。
- **i18n**：全部文案走 `useT()`；不得硬编码中文；新增 key 同时写入两包（key-set 测试必须绿）。
- **测试**：Vitest + Testing Library；用 fake `pickerAPI` 注入（参考 `frontend/src/test/settings-harness.tsx` 的做法，新建 `picker-harness.tsx`）；每个任务一次 commit；`npm run test:web` 与 `npm run build:web` 必须绿。
- 禁止 Rare UI 根入口；`npm run lint:imports` 必须通过。
