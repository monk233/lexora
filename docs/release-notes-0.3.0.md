# Lexora v0.3.0 发布说明

发布日期：2026-10-27  
构建：`Lexora-0.3.0-win-x64.exe`（Windows 10/11 x64，免安装单文件）

## 主要变更

### 1. 截图标注（纯本地）

框选后可直接标注，全部本地绘制，不调用 AI：

- **形状**：矩形 / 圆形 / 直线，描边或实心填充，颜色与粗细可调；
- **箭头**：实心三角头 + 锥形尾；
- **画笔**：自由绘制；
- **文本**：颜色、字号、粗体、文字背景；
- **序号**：自动递增；
- **马赛克**：块大小可调。

颜色按钮展开 10 个预设色 + 自定义 HSV 取色面板与吸色器。属性栏随工具切换，默认在工具条下方，空间不足时翻到上方。

### 2. 标注编辑

- 点击标注选中：包围盒 + 8 个缩放柄 + 旋转柄；
- 移动、自由/单轴缩放、旋转（Shift 吸附 15°）、`Delete` 删除；
- 新画的标注不自动选中；所有变换一步撤销/重做；
- 标注限制在框选范围内，并合成进复制、图片技能、钉在桌面的导出图。

### 3. 钉在桌面

把框选（含标注）钉成置顶无边框窗口：拖动移动、悬停复制/关闭、双击或 `Esc` 关闭。支持滚轮缩放（每格约 10%，最小 15%，放大无上限，以左上角为锚点）；超长图保持可读宽度并在窗口内滚动。

### 4. 钉图编辑与属性栏

钉图右上角提供编辑 / 复制 / 关闭按钮。编辑模式复用截图工具栏与属性栏：形状、箭头、画笔、文字、序号、马赛克、撤回/重做、提取文字/翻译/解释图片、自定义图片技能、取消/确认；工具栏固定单行显示在图片外，属性栏位于其下方。`Esc` 顺序：吸管 → 颜色面板 → 取消工具 → 退出编辑。

### 5. 长截图

- 进入后选区保持可见，控制栏出现在选区下方（方向切换 / 取消 / 完成 / 帧数尺寸）；
- 预览窗口为选区侧边、底部对齐，透明无白底，只保留与选区同色同粗细的 2px 边框；高度固定、宽度随拼接长度按比例变窄（最小 90），窗口随拼接节流 resize；
- **自动滚动**：控制栏一键开启，由程序按稳定步长滚动目标应用并等待渲染稳定后抓帧，不再依赖手动滚动；光标进入选区才滚动、移出即停，按钮在「自动滚动 / 停止滚动」间切换，到页底自动停止；手动滚动始终可用；
- 抓帧使用持续 WGC 捕获会话（不再每帧新建），支持竖向/横向与来回滚动、方向切换后从当前屏幕重新同步；
- 完成后复制并钉图，长图整图适配窗口；取消或按 `Esc` 恢复截图界面。

### 6. 截图体验

- 进入截图后默认不显示全屏选区：鼠标所在窗口自动吸附高亮，点击窗口或拖动框选后才出现工具栏，点击空白桌面/任务栏即全屏选区；
- 取色放大镜：鼠标旁放大 15×15 像素，显示坐标与 `#RRGGBB`，`C` 复制色号；
- 跨显示器框选与跨屏移动/缩放，选区为全局物理矩形；
- 截图 overlay 可被系统截图/录屏拍到；截图过程中再次触发截图会被忽略。

### 7. 服务商与模型

- 新增 **OpenCode Go** 预设：服务地址 `https://opencode.ai/inference/go/openai/v1`，模型列表从 `https://opencode.ai/inference/go/v1/models` 拉取，请求自动附带 `x-opencode-session` 会话头与 `Lexora/<版本>` User-Agent；
- 连接测试允许空内容/截断的探针响应（部分推理模型在极小 `max_tokens` 下返回空 `content`）；
- 本地模型：Hy-MT2 1.8B（翻译）、Qwen2.5 3B（通用）、Qwen2.5-VL 3B（视觉，含视觉投影器），可同时下载、按功能自动选择。

### 8. 设置与文档

- 设置页文案精简：字段说明、模型描述、错误提示与工具提示只保留功能/用途；
- 文本技能中的「截图」点击后隐藏划词工具栏（与「复制」一致）；
- CI 改为仅在推送 release tag（`v*`）或手动触发时运行；
- README、CHANGELOG、用户指南、构建与架构文档去除口号与来源引用，保留功能、命令与参数等技术事实。

## 升级说明

- **设置自动迁移（schema v6）**：旧配置中的自定义图片技能一次性迁移到截图工具条；`captureSkills` 合并新增本地工具（保留用户顺序），「复制」条目移除（确认按钮即复制并退出）。
- 旧版本的自定义技能、模型、快捷键等均保留；`data/` 目录不受影响。
- 新增设置字段 `provider.online.modelsBaseUrl`；旧设置文件自动兼容（为空时回退服务地址）。

## 已知限制

- 截图/长截图受 Windows UIPI 限制：管理员权限窗口可能无法滚动或拼接。
- 长截图依赖目标应用响应滚轮：视频/动画、固定悬浮层可能造成拼接错位；横向需目标内容支持左右滚动。
- 自动滚动用于常见网页/文档；特殊滚动容器（自绘滚动、虚拟列表）可能无法滚动，需改用手动滚动。
- 文字/序号标注缩放按字号等比调整，极端单轴缩放时包围盒可能略有差异。
- 图片理解需要在线视觉模型或本地 Qwen2.5-VL 3B（内置 Qwen2.5 3B 为纯文本模型，不能看图）。

## 安装与验证

1. 下载 `Lexora-0.3.0-win-x64.exe`，放到任意可写目录，双击运行（静默启动，驻留托盘）。
2. 数据保存在 exe 同级 `data/`（设置、模型、引擎、日志）。
3. 构建校验：`cargo test` 全部通过；`cargo fmt --check` 通过；`node --check` 覆盖全部前端脚本。
