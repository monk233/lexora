# Lexora v0.3.0 发布说明

发布日期：2026-10-26  
构建：`Lexora-0.3.0-win-x64.exe`（Windows 10/11 x64，免安装单文件）

## 主要变更

### 1. 截图标注工具（纯本地）

框选后可直接在截图上标注，全部本地绘制、不调用 AI：

- **形状**：矩形 / 圆形 / 直线，支持描边与实心填充（不透明度 100%），颜色与粗细可调；
- **箭头**：实心三角形箭头 + 锥形尾巴，头部随粗细缩放；
- **画笔**：自由绘制，颜色/粗细可调；
- **文本**：颜色、字号、粗体、文字背景填充色；
- **序号**：自动递增的圆形序号；
- **马赛克**：涂抹打码，像素块大小可调。

颜色按钮（色块在左、下拉箭头在右）展开 10 个预设色 + 自定义 HSV 取色面板（饱和度/明度区、色相条、RGB 输入、预览）以及吸色器（直接点截图取色）。属性栏随工具切换，默认在工具条下方，空间不足时翻到上方。

### 2. 标注可选中、可变换、可撤销

- 点击已画好的标注即可选中：虚线包围盒 + 8 个缩放柄 + 旋转柄；
- 支持移动、自由/单轴缩放、旋转（Shift 吸附 15°）、`Delete` / `Backspace` 删除；
- 新画的标注不会自动选中，点击后才出现手柄；
- 所有变换一步撤销/重做，拖动中实时预览；
- 标注自动限制在框选范围内，并合成进复制/确认/图片技能/钉在桌面的导出图。

### 3. 钉在桌面

把框选（含标注）钉成置顶无边框窗口：拖动移动、悬停复制/关闭、双击或 `Esc` 关闭；超长图保持可读宽度并在窗口内滚动（普通图片不出现滚动条）。

### 4. 长截图（手动滚动）

- 点击「长截图」后选区保持可见（框内实时显示目标应用），侧边出现预览窗口（左右自适应、不抢焦点）；
- 用滚轮上下 / 左右来回滚动目标应用即可实时拼接，支持竖向/横向方向切换；
- 预览窗口按 revision 事件驱动刷新（约 720px 下采样 + 双缓冲淡入）；
- 完成 = 复制到剪贴板并弹出钉图窗口；取消 = 恢复截图界面继续操作；
- 全程不自动滚动，也不限制滚动方向。

### 5. 截图体验与设置

- 截图界面不再对系统截图/录屏隐藏；已在截图时再次触发截图会被忽略并提示「已经在截图了」；
- 退出截图单帧隐藏（禁用 DWM 过渡），不闪烁、不抖动；
- 设置页「图片技能」为统一列表：本地工具 + 提取文字/翻译/解释图片 + 自定义图片技能，可开关、拖动排序；翻译/解释图片支持编辑系统提示词。

## 升级说明

- **设置自动迁移（schema v6）**：旧配置中的自定义图片技能会一次性迁移到截图工具条；`captureSkills` 合并新增的本地工具（保留用户顺序），「复制」条目被移除（确认按钮即复制并退出）。
- 旧版本的自定义技能、模型、快捷键等均保留；`data/` 目录不受影响。
- 之前手动关闭过的工具不会被强行重新打开，只迁移从未出现在设置里的新工具。

## 已知限制

- 截图/长截图受 Windows UIPI 限制：管理员权限窗口可能无法滚动或拼接。
- 长截图依赖目标应用响应滚轮：视频/动画、固定悬浮层可能出现拼接错位（会提示「滚动过快或方向不符」）；横向需目标内容支持左右滚动。
- 文字/序号标注缩放按字号等比调整，极端单轴缩放时包围盒可能略有差异。
- 图片理解需要在线视觉模型或本地 Qwen2.5-VL 3B（内置 Qwen2.5 3B 为纯文本模型，不能看图）。

## 安装与验证

1. 下载 `Lexora-0.3.0-win-x64.exe`，放到任意可写目录，双击运行（静默启动，驻留托盘）。
2. 数据保存在 exe 同级 `data/`（设置、模型、引擎、日志）。
3. 构建校验：
   - `cargo test`：**242 passed / 0 failed / 2 ignored**；
   - `cargo fmt --check` 通过；
   - `node --check` 覆盖全部前端脚本；
   - release 单文件：`Lexora-0.3.0-win-x64.exe`，11,034,112 字节（约 10.5 MB），SHA256 `340b22c0318021a3a2938a694f38ad9f462b8a0c680399f6e66d71af6faa3451`。
