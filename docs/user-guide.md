# 使用指南

## 安装与启动

Lexora 是免安装应用：

1. 从 [Releases](https://github.com/monk233/lexora/releases) 下载 `Lexora-<version>-win-x64.exe`。
2. 放到任意可写目录（建议不在 `Program Files` 等受限目录下，否则数据会写入 `%APPDATA%`）。
3. 双击 `Lexora-<version>-win-x64.exe`。

双击后**静默启动**，不弹窗口，程序直接在系统托盘后台运行。右键托盘图标（或双击托盘图标）选择「显示设置」完成配置；配置完成后关闭设置窗口，程序继续驻留托盘。要完全退出，使用设置页「退出程序」或托盘菜单「退出」。再次双击 exe 也只会在后台启动，不会重复打开窗口。

> Windows 11 默认把新托盘图标收进「^」溢出区，可拖动到任务栏常驻。

## 配置翻译服务

### 在线 API

1. 设置 → 翻译服务 → 选择「在线 API」。
2. 选择预设（DeepSeek / OpenAI / Moonshot / 智谱 / Ollama / LM Studio / 自定义）。切换预设会清空上一个服务商的 API Key 与模型名，只填入新预设的服务地址，避免把旧配置带到新服务上。
3. 填入 API Key，然后点「拉取模型」从服务端 `/models` 读取可用模型并选择；不会自动填写模型名。服务端不支持 `/models` 时选「自定义模型…」手动填写。
4. 点「测试连接」，成功后即可使用。

### 自定义技能提示词

设置 → 划词行为 → 工具栏技能 → 点某个技能右侧的「编辑提示词」图标，会在该技能下方展开提示词文本域：

- 文本域默认填入系统默认提示词（英文）；可直接修改，改动自动保存，下一次翻译/总结/解释/润色立即生效。
- 翻译提示词支持 `{target}` 占位符，会在请求时替换成目标语言（如 `Simplified Chinese`）；如果自定义提示词里没有占位符，会自动在末尾补一行 `Target language: <语言>`。
- 点「重置为默认」清空自定义内容，恢复系统默认提示词。
- 「朗读」「复制」「搜索」不调用大模型，没有提示词。

### 搜索技能

工具栏默认带「搜索」按钮：选中文本后点击，会用默认浏览器在所选搜索引擎中搜索这段文字。

- 设置 → 划词行为 → 工具栏技能 → 点「搜索」右侧的「配置」按钮，展开搜索引擎面板。
- 可选 **Google**、**百度**、**Bing**，选择后立即生效；搜索词会自动 URL 编码。

### 自定义技能

设置 → 划词行为 → 工具栏技能 → 点「添加技能」，即可创建自己的划词技能：

- 选择图标：点击「更换图标」展开 200 个内置图标（支持搜索过滤），选中即收起；填写名称（最多 20 字）、提示词（必填）。
- 提示词支持变量：`{text}` 选中文本、`{target}` / `{language}` 目标语言（英文名）、`{program}` / `{app}` 当前应用名；未识别的变量会原样保留。
- 示例：`请从用户选中的文本中提取 5 个关键词，用逗号分隔输出：\n{text}`
- 保存后技能立即出现在工具栏；可随时编辑、删除、拖拽排序或关闭。删除后不会影响内置技能。
- 点「恢复默认」会重置其他设置，但**保留自定义技能**（定义与启用状态都不丢失）。

### 本地模型（离线）

1. 设置 → 翻译服务 → 选择「本地模型」。
2. 点「下载引擎」（llama.cpp，约 23MB）并等待完成。
3. 在模型目录下载模型（只提供两个，可同时下载多个），或「导入 GGUF」使用本机已有模型：
   - **腾讯混元 Hy-MT2 1.8B（翻译模型，推荐）**：Q4_K_M，约 1.1GB，翻译专用，速度快。
   - **Qwen2.5 3B（通用模型）**：Q4_K_M，约 2.0GB，翻译、总结、解释都能用，需要更多内存。
4. 点「启动」，状态变为「运行中」。不需要选择模型：翻译自动使用 Hy-MT2，总结/解释自动使用 Qwen2.5 3B（未安装首选模型时自动回退到已安装的模型）。
5. 点「停止」后本地引擎保持停止：再次翻译/总结不会自动启动，需要重新点「启动」。切换功能模型时会重新加载 llama-server，可能需要等待一段时间。
6. 运行状态会被记住：点「启动」后退出程序，下次打开 Lexora 会自动在后台恢复本地引擎；只有主动点「停止」才会清除这个状态。

完全离线环境可手动放置文件：

```
<程序目录>\data\engine\llama-server.exe（及同目录 DLL）
<程序目录>\data\models\*.gguf
```

放好后回到设置页刷新即可。

## 日常使用

1. 在任意应用中**拖动选中**一段文字，鼠标旁弹出工具栏。
2. 也可**双击单词 / 三击段落**选中文字，同样会弹出工具栏（单次点击不会弹出）。
3. 工具栏是**非激活浮层**：弹出后键盘焦点仍在原应用，`Delete`、`Ctrl+C`、`Ctrl+X` 等快捷键照常生效；一旦你按键、右键或点击别处，未固定的工具栏会自动隐藏。**鼠标滚轮 / 触摸板滚动不会隐藏工具栏**。
4. 点击「翻译」：结果面板流式显示译文（按 Markdown 渲染：标题、列表、代码块、表格、链接等）；可在面板顶部切换目标语言（38 种语言）；「固定」可把结果留在桌面，点击「×」关闭；拖动结果面板标题栏空白处可移动工具栏位置；拖动右下角手柄可调整面板大小（会记住，双击恢复自动）；内容过长时在面板内滚动即可阅读。
5. 「总结」「解释」用简体中文处理选中文本，结果流式显示；「润色」让文字更通顺自然（提示词可改）；结果下方「继续提问」可基于原文和历史回答多轮流式追问。选中单个英文单词时，翻译/解释会给出词典式释义（音标、核心用法、高频场景）和 3 个建议追问。
6. 「朗读」用 Windows 系统语音朗读；朗读中再次点击会停止朗读（不会提示失败）；「复制」复制原文；「搜索」用设置好的搜索引擎（Google / 百度 / Bing）在浏览器中搜索选中文字。

### 更多菜单

- 技能太多时，超出的技能会自动收进「更多」面板顶部，并与下方配置项用分隔线隔开；菜单可滚动。
- **在此应用中禁用**：把当前应用加入黑名单（例如微信、游戏）。
- **划词设置…**：打开设置窗口。
- **禁用划词工具**：临时关闭划词功能，可在设置中重新启用。

## 设置说明

| 设置 | 说明 |
| --- | --- |
| 技能分类 | 工具栏技能按「文字技能 / 图片技能」两个 Tab 分类展示：「文字技能」= 翻译、总结、解释、润色、搜索、朗读、复制、截图入口、自定义文字技能；「图片技能」= 截图工具条的全部条目：钉在桌面/形状/箭头/画笔/文字/序号/马赛克/提取文字/翻译/解释图片/长截图 + 自定义图片技能（统一列表，可任意开关与拖动排序，顺序即截图工具条顺序）。图片技能可全部关闭 |
| 截图快捷键 | 独立「快捷键」卡片中配置：截图功能的全局快捷键，默认 Win+Shift+X；点击后按下新的组合键即可修改 |
| 技能提示词 | 每个大模型技能（翻译/总结/解释/润色）可编辑 system prompt，默认英文，可重置 |
| 搜索配置 | 「搜索」技能右侧配置按钮选择 Google / 百度 / Bing |
| 恢复默认 | 重置所有选项，但保留自定义技能、已下载的模型与引擎 |
| 本地模型 | 显示已安装模型；点「启动/停止」控制引擎，模型按功能自动选择 |
| 紧凑模式 | 只显示图标，不显示文字 |
| 默认目标语言 | 「自动识别」时中文译为英文、其他语言译为中文；也可选 38 种语言之一 |
| 应用黑名单 | 这些程序里不弹出工具栏 |
| 模型名 | 在线 API 的模型列表，点「拉取模型」从 `/models` 获取 |
| 开机自启 | 登录 Windows 后自动在托盘启动；便携单文件版不支持 |
| 关闭窗口后驻留托盘 | 关闭设置窗口时保持后台运行（默认开） |

## 数据与隐私

- 配置文件、模型、日志都保存在程序目录 `data/`（不可写时使用 `%APPDATA%\Lexora`）。
- 在线模式只把选中文本发送到你配置的服务地址；本地模式不联网。
- 日志不记录 API Key。
- 「关于」页可打开数据目录、查看版本与引擎状态。

## 检查更新

设置 → 关于 → 点「检查更新」：

- 自动查询 GitHub 最新 Release；已是最新会直接提示当前版本。
- 有新版本时显示版本号、更新说明、大小与发布时间；点「下载并更新」后会自动下载、替换当前 exe，并重启到新版本（设置窗口会重新打开）。
- 更新只替换程序本体，不动 exe 同级的 `data/` 目录（配置、模型、日志都保留）。
- 如果程序所在目录不可写（例如放在 `C:\Program Files` 且非管理员运行），会提示改用可写目录或手动下载。
- 更新过程中会生成临时文件 `Lexora-update-<版本>.exe` 与 PowerShell 助手脚本；成功后自动清理，旧 exe 备份为 `.old` 并在启动后删除。

## 故障排查

- **工具栏不出现**：确认划词已启用、未在「应用黑名单」中；部分应用（PDF 阅读器、管理员权限应用）不支持取词。
- **翻译报「服务未配置/Key 无效」**：检查在线服务地址是否以 `/v1` 结尾、API Key 是否正确，点「测试连接」查看具体错误。
- **本地模型启动失败**：确认 `data/engine/llama-server.exe` 存在、模型文件完整；日志在 `data/logs/llama.log`。
- **朗读无声音**：Windows 设置 → 时间和语言 → 语音，确认已安装语音包。
- **程序无法启动**：查看 `data/logs/main.log`；如果提示缺少 WebView2，请安装 Microsoft Edge WebView2 Runtime。


## 截图标注与基础工具

在截图 overlay 中框选区域后，可用工具条上的基础工具（全部本地处理，不调用 AI）：

- **形状**：矩形 / 圆形 / 直线（三个按钮切换）；矩形和圆形支持「描边 / 填充」两种模式，直线只有描边；颜色和粗细可调。
- **箭头**：拖动画出带箭头的直线，颜色/粗细可调。
- **画笔**：按住自由绘制，颜色/粗细可调。
- **文本**：点击定位后输入文字，支持颜色、字号、粗体与文字背景填充色。
- **序号**：点击放置自动递增的圆形序号（1、2、3…），配色/字号可调。
- **马赛克**：按住涂抹即可打码，像素块大小可调。
- **撤回 / 重做**：工具条上的撤销/重做按钮，或 `Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z`（属性栏不提供「清除标注」，撤回即可）。
- 形状/箭头/画笔在拖动过程中实时显示，松开鼠标才确认（可一步撤回）；截图界面本身不隐藏，系统截图/录屏可以看到；已经在截图时再次触发截图会被忽略（不会重复抓屏）。
- 颜色选择（QQ 风格）：点击颜色按钮展开 10 个预设色 + 「自定义」；自定义面板提供饱和度/明度取色区、色相条、RGB 输入与预览；吸管可点截图任意位置直接吸取颜色。
- 属性栏随当前工具显示对应选项（默认在工具条下方，空间不足自动翻到上方）：颜色、粗细、填充模式、字号、粗体、文字背景、马赛克块大小；不提供「清除标注」（撤回即可）。

导出的图片会带上全部标注（复制、确认、提取文字/翻译/解释图片、钉在桌面都按合成后的图片处理）。

- **钉在桌面**：把当前框选（含标注）钉成置顶小窗；按住拖动移动位置，双击或 `Esc` 关闭，悬停右上角可复制/关闭。长截图等超高图片会保持可读宽度，鼠标滚轮可在钉图窗口内上下滚动。
- **长截图**：点击后选区侧边出现预览窗口（左/右自适应），自己缓慢滚动目标应用即可实时拼接；预览窗口可切换「竖向 / 横向」方向，完成后复制到剪贴板并弹出钉图窗口，「取消」则回到截图界面继续操作（不再自动滚动）。

## 截图

- 点击工具栏的「截图」技能，或按 **Win+Shift+X**（默认快捷键，可在设置 → 快捷键卡片中修改）：屏幕几乎立即进入截图框选，不再有黑屏加载或闪屏。
- 截图时设置窗口与划词工具面板保持打开，并且会出现在截取的画面里；框选期间全屏 overlay 会覆盖它们，退出截图后仍在原处（不再被关闭）。
- 截图工具条的「复制 / 提取文字 / 翻译 / 解释图片」可以在设置 → 划词行为 → 图片技能 中开关与排序。
- 默认选中整屏；**此时直接在屏幕上按住拖动即可重新框选**。把选区缩小后，在选区**内部**按住拖动可平移选区；拖 8 个手柄可调整大小，左上角实时显示宽×高。Esc 取消。
- 工具条（与划词工具栏同款白色主题）：
  - **复制**：把框选区域作为图片写入剪贴板，然后退出截图。
  - **取消 / 确认**：工具条末尾固定显示（确认最右、绿色）。确认 = 复制框选图片到剪贴板并退出；取消 = 直接退出（`Esc` 同效）。
- 截图工具条会带上所有启用的图片技能（含自定义图片技能）；紧凑模式下只显示图标。
  - **提取文字 / 翻译 / 解释图片 / 图片技能**：自动退出截图、把图片复制到剪贴板，并在划词面板中流式显示结果（提取文字为纯文本，翻译/解释为 Markdown）；面板支持朗读、复制、重试与继续提问，和文字技能面板完全一致。
- 提取文字优先使用视觉模型转写（比 Windows OCR 准确）且**流式输出**：在线模式直接用你配置的视觉模型；本地模式使用 Qwen2.5-VL 3B。两者都不可用或失败时自动回退系统 OCR，保证功能可用。
- 图片翻译的目标语言可以在结果面板里直接切换（源语言固定为「自动识别」）；面板会显示实际使用的目标语言。
- 自定义「图片」技能：在设置 → 划词行为 → 自定义技能中把类型切为「图片」，工具栏点击该技能后进入截图，框选后点击左上角的技能按钮对图片执行提示词。
- 图片理解：在线模式使用任意 OpenAI 兼容的视觉模型；本地模式需在设置 → 本地模型下载 **Qwen2.5-VL 3B（视觉模型）**（含视觉投影器 mmproj）。注意内置的 Qwen2.5 3B 是纯文本模型，不能看图。
