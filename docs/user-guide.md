# 使用指南

## 安装与启动

Lexora 是免安装应用：

1. 从 [Releases](https://github.com/monk233/lexora/releases) 下载 `Lexora-<version>-win-x64.exe`。
2. 放到任意可写目录（不建议放在 `Program Files` 等受限目录，否则数据会写入 `%APPDATA%`）。
3. 双击 `Lexora-<version>-win-x64.exe`。

双击后静默启动，不弹窗口，程序在系统托盘后台运行。右键托盘图标（或双击托盘图标）选择「显示设置」完成配置；关闭设置窗口后程序继续驻留托盘。要完全退出，使用设置页「退出程序」或托盘菜单「退出」。再次双击 exe 只在后台启动，不会重复打开窗口。

> Windows 11 默认把新托盘图标收进「^」溢出区，可拖动到任务栏常驻。

## 配置翻译服务

### 在线 API

1. 设置 → 翻译服务 → 选择「在线 API」。
2. 选择预设（DeepSeek / OpenAI / Moonshot / 智谱 / OpenCode Go / Ollama / LM Studio / 自定义）。切换预设会清空上一个服务商的 API Key 与模型名，只填入新预设的服务地址（OpenCode Go 额外使用独立的模型列表地址，请求自动附带 `x-opencode-session` 头）。
3. 填入 API Key，点「拉取模型」从服务端 `/models` 读取可用模型并选择；不会自动填写模型名。服务端不支持 `/models` 时选「自定义模型…」手动填写。
4. 点「测试连接」，成功后即可使用。

### 自定义技能提示词

设置 → 划词行为 → 工具栏技能 → 点技能右侧的「编辑提示词」图标，在该技能下方展开提示词文本域：

- 文本域默认填入系统默认提示词（英文），可直接修改，改动自动保存，翻译/总结/解释/润色立即生效。
- 翻译提示词支持 `{target}` 占位符，请求时替换为目标语言（如 `Simplified Chinese`）；提示词中没有占位符时，自动在末尾补一行 `Target language: <语言>`。
- 点「重置为默认」清空自定义内容，恢复系统默认提示词。
- 「朗读」「复制」「搜索」不调用大模型，没有提示词。

### 搜索技能

工具栏默认带「搜索」按钮：选中文本后点击，用默认浏览器在所选搜索引擎中搜索这段文字。

- 设置 → 划词行为 → 工具栏技能 → 点「搜索」右侧的「配置」，展开搜索引擎面板。
- 可选 Google、百度、Bing，选择后立即生效；搜索词自动 URL 编码。

### 自定义技能

设置 → 划词行为 → 工具栏技能 → 点「添加技能」创建自己的划词技能：

- 选择图标：点「更换图标」展开 200 个内置图标（支持搜索过滤），选中即收起；填写名称（最多 20 字）与提示词（必填）。
- 提示词变量：`{text}` 选中文本、`{target}` / `{language}` 目标语言（英文名）、`{program}` / `{app}` 当前应用名；未识别的变量原样保留。
- 示例：`请从用户选中的文本中提取 5 个关键词，用逗号分隔输出：\n{text}`
- 保存后技能立即出现在工具栏；可编辑、删除、拖拽排序或关闭。删除不影响内置技能。
- 点「恢复默认」重置其他设置，但保留自定义技能（定义与启用状态都不丢失）。

### 本地模型（离线）

1. 设置 → 翻译服务 → 选择「本地模型」。
2. 点「下载引擎」（llama.cpp，约 23MB）并等待完成。
3. 在模型目录从 ModelScope 下载所需模型（支持同时下载多个），或「导入 GGUF」使用本机已有模型：
   - **Qwen3.5（翻译 / 通用 / 视觉）**：0.8B、2B、4B 各提供 Q4_K_M、Q3_K_M，每种都支持翻译、通用文本任务和图片理解。下载包含对应的 mmproj-F16 视觉投影器，主文件和投影器都完整才算安装完成。
4. 在设置中手动选择一个 Qwen3.5 本地模型，再点「启动」。文本翻译、总结、解释、润色、自定义技能及图片 OCR、翻译、解释共用这个选择，选择会被保存。未选择时所有本地 AI 任务不可用，不自动替选；硬件检测只显示推荐标签和理由（内存与线程决定档位，大显存可升一档；内置引擎为 CPU 版，显存不改变实际速度）。
5. 切换选择后需重启本地引擎。点「停止」后引擎保持停止：再次发起请求不会自动启动，需要重新点「启动」。翻译与其他本地 AI 任务均复用所选 Qwen3.5。


6. 运行状态会被记住：点「启动」后退出程序，下次打开 Lexora 会自动在后台恢复本地引擎；只有主动点「停止」才会清除。

本地模型迁移兼容：旧 Hy-MT2 和 Qwen2.5 文件不自动删除，仅作为「其他本地模型」显示并支持手动删除，不再提供内置下载、自动选择或推荐。所有本地 AI 任务使用 `provider.local.selectedModel` 手动选择的 Qwen3.5；未选择时本地 AI 不可用，追问建议与入口静默隐藏。

完全离线环境可手动放置文件：

```
<程序目录>\data\engine\llama-server.exe（及同目录 DLL）
<程序目录>\data\models\*.gguf
```

放好后回到设置页刷新即可。

## 日常使用

1. 在任意应用中拖动选中一段文字，鼠标旁弹出工具栏。
2. 也可双击单词 / 三击段落选中文字，同样会弹出工具栏（单次点击不会弹出）。
3. 工具栏是非激活浮层：弹出后键盘焦点仍在原应用，`Delete`、`Ctrl+C`、`Ctrl+X` 等快捷键照常生效；按键、右键或点击别处时，未固定的工具栏自动隐藏。鼠标滚轮 / 触摸板滚动不会隐藏工具栏。
4. 点击「翻译」：结果面板以固定宽度流式显示译文（按 Markdown 渲染：标题、列表、代码块、表格、链接等），高度随内容增长并受屏幕上限约束；达到上限后滚动条隐藏，内容继续自动滚动，向上翻阅时暂停跟随。面板顶部可切换目标语言（38 种语言）；「固定」把结果留在桌面，点「×」关闭；拖动面板标题栏空白处可移动位置。
5. 「总结」「解释」用简体中文处理选中文本，结果流式显示；「润色」输出更通顺的改写（提示词可改）；选中单个单词或短语时，翻译/解释默认给简短词条（含音标或拼音、最多 3 个常见义项、可选 1 个短例），疑似错拼先询问，音标与拼音由模型生成。解释默认聚焦核心含义，通常 150–250 字，简单内容更短。所有 AI 文字/图片技能完成后，结果下方可输入问题或点击模型动态生成的追问建议（最多 3 条，不使用固定预设）；每轮成功回答后刷新建议。追问结合原文、初始回答和多轮历史，保留最近 10 轮，单段最多 4000 字符，总文本预算 20000 字符，超限时优先保留最近问答。在线使用已配置的在线模型；本地仅使用手动选择且完整安装的 Qwen3.5 本地模型；未选择或安装不完整时，建议区和追问入口静默隐藏，不显示提示，也不请求建议。建议生成失败不提示，不影响已有结果。

动态追问时序：主回答收到首个非空 chunk 后启动建议预取；每次最多 3 条。主回答或本轮追问完成时，已有预取结果立即展示，否则最多等待 3000 ms；超时取消并静默丢弃迟到结果，不显示固定建议。该截止仅限制前端等待时间，不保证实机模型能在 3 秒内成功生成建议。多轮追问继续保留原文、初始回答与历史；建议生成另用精简上下文（原文和初始回答各最多 800 字符，最近 6 轮每段最多 500 字符，总计最多 3000 字符，输出最多 80 tokens），普通多轮追问预算保持不变。
6. 「朗读」用 Windows 系统语音朗读，朗读中再次点击停止；「复制」复制原文；「搜索」用设置好的搜索引擎（Google / 百度 / Bing）在浏览器中搜索选中文字。

### 更多菜单

- 技能太多时，超出的技能自动收进「更多」面板顶部，与下方配置项用分隔线隔开；菜单可滚动。
- **在此应用中禁用**：把当前应用加入黑名单（例如微信、游戏）。
- **划词设置…**：打开设置窗口。
- **禁用划词工具**：临时关闭划词功能，可在设置中重新启用。

## 数据与隐私

- 配置文件、模型、日志都保存在程序目录 `data/`（不可写时使用 `%APPDATA%\Lexora`）。模型调用日志为 `logs/model.log`，包含耗时、分块数、状态与 provider/model，不记录提示词和回答正文。
- 在线模式只把选中文本发送到你配置的服务地址；本地模式不联网。
- 日志不记录 API Key；`main.log`、`model.log`、`llama.log` 达到 10MB 时自动分卷并只保留一个最近历史分卷。
- 「关于」页可打开数据目录、查看版本与引擎状态。

## 检查更新

Lexora 启动后由后台静默查询 GitHub 最新 Release，并每 6 小时复查一次；即使设置窗口关闭，发现新版本时也会弹 Windows 系统通知，同一版本只通知一次。打开「关于」即可看到发现结果，也可点「检查更新」手动刷新。

- 已是最新会显示当前版本。
- 有新版本时显示版本号、Markdown 更新说明、大小与发布时间；点「下载并更新」后自动下载、替换当前 exe，并重启到新版本（设置窗口会重新打开）。
- 更新只替换程序本体，不动 exe 同级的 `data/` 目录（配置、模型、日志都保留）。
- 程序所在目录不可写时（例如放在 `C:\Program Files` 且非管理员运行），会提示改用可写目录或手动下载。
- 更新过程中会生成临时文件 `Lexora-update-<版本>.exe` 与 PowerShell 助手脚本；成功后自动清理，旧 exe 备份为 `.old` 并在启动后删除。

## 故障排查

- **工具栏不出现**：确认划词已启用、未在「应用黑名单」中；部分应用（PDF 阅读器、管理员权限应用）不支持取词。
- **翻译报「服务未配置/Key 无效」**：检查在线服务地址是否以 `/v1` 结尾、API Key 是否正确，点「测试连接」查看具体错误。
- **本地模型启动失败**：确认 `data/engine/llama-server.exe` 存在、模型文件完整；日志在 `data/logs/llama.log`。
- **在线 API 偶发空结果**：查看 `data/logs/model.log`。若提示“只返回了推理内容”，说明推理模型可能耗尽最大输出 token；提高设置中的最大输出 token，或改用普通对话模型。
- **朗读无声音**：Windows 设置 → 时间和语言 → 语音，确认已安装语音包。
- **程序无法启动**：查看 `data/logs/main.log`；如果提示缺少 WebView2，请安装 Microsoft Edge WebView2 Runtime。

## 截图标注与基础工具

在截图 overlay 中框选区域后，可用工具条上的基础工具（全部本地处理，不调用 AI）：

- **形状**：矩形 / 圆形 / 直线（三个按钮切换）；矩形和圆形支持「描边 / 填充」两种模式，直线只有描边；颜色和粗细可调。
- **箭头**：拖动画出带箭头的直线，颜色/粗细可调。
- **画笔**：按住自由绘制，颜色/粗细可调。
- **文本**：点击定位后输入文字，支持颜色、字号、粗体与文字背景填充色。
- **序号**：点击放置自动递增的圆形序号（1、2、3…），配色/字号可调。
- **马赛克**：按住涂抹即可打码，像素块大小可调。
- **撤回 / 重做**：工具条上的撤销/重做按钮，或 `Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z`（属性栏不提供「清除标注」，撤回即可）。
- **选中与编辑**：点击已画好的标注显示 8 个缩放柄 + 旋转柄；拖动内部移动、拖角柄自由缩放、拖边柄单轴缩放、拖旋转柄旋转（Shift 吸附 15°）；`Delete` / `Backspace` 删除选中的标注；新画的标注不会自动选中，点击后才出现手柄；所有变换都可一步撤销/重做。
- 形状/箭头/画笔在拖动过程中实时显示，松开鼠标才确认（可一步撤回）；截图界面本身不隐藏，系统截图/录屏可以看到；已经在截图时再次触发截图会被忽略（不会重复抓屏）。
- 颜色选择：点击颜色按钮展开 10 个预设色 + 「自定义」；自定义面板提供饱和度/明度取色区、色相条、RGB 输入与预览；吸管可点截图任意位置直接吸取颜色。
- 属性栏随当前工具显示对应选项（默认在工具条下方，空间不足时翻到上方）：颜色、粗细、填充模式、字号、粗体、文字背景、马赛克块大小。

导出的图片会带上全部标注（复制、确认、提取文字/翻译/解释图片、钉在桌面都按合成后的图片处理）。

- **钉在桌面**：把当前框选（含标注）钉成置顶小窗；按住拖动移动位置，双击或 `Esc` 关闭，悬停右上角可复制/关闭。长截图等超高图片会保持可读宽度，鼠标滚轮可在钉图窗口内上下滚动。
- **长截图**：点击后选区保持可见（框内实时显示目标应用），侧边出现预览窗口（左/右自适应）；滚动鼠标滚轮即可上下/左右来回滚动目标应用，预览实时拼接；预览窗口可切换「竖向 / 横向」，完成后复制到剪贴板并弹出钉图窗口，「取消」则回到截图界面继续操作（全程不自动滚动）。

## 截图

- 点击工具栏的「截图」技能，或按 **Win+Shift+X**（默认快捷键，可在设置 → 快捷键卡片中修改）：进入截图框选，不再有黑屏加载或闪屏。
- 截图时设置窗口与划词工具面板保持打开，并会出现在截取的画面里；框选期间全屏 overlay 覆盖它们，退出截图后仍在原处（不再被关闭）。
- 截图工具条的「复制 / 提取文字 / 翻译 / 解释图片」可在设置 → 划词行为 → 图片技能中开关与排序。
- 默认选中整屏；此时直接在屏幕上按住拖动即可重新框选。把选区缩小后，在选区内部按住拖动可平移选区；拖 8 个手柄可调整大小，左上角实时显示宽×高。`Esc` 取消。
- 工具条（与划词工具栏同款白色主题）：
  - **复制**：把框选区域作为图片写入剪贴板，然后退出截图。
  - **取消 / 确认**：工具条末尾固定显示（确认最右、绿色）。确认 = 复制框选图片到剪贴板并退出；取消 = 直接退出（`Esc` 同效）。
- 截图工具条会带上所有启用的图片技能（含自定义图片技能）；紧凑模式下只显示图标。
  - **提取文字 / 翻译 / 解释图片 / 图片技能**：自动退出截图、把图片复制到剪贴板，并在划词面板中流式显示结果（提取文字为纯文本，翻译/解释为 Markdown）；面板支持朗读、复制、重试与继续提问，与文字技能面板一致。
- 提取文字优先使用视觉模型转写（比 Windows OCR 准确）且流式输出：在线模式直接用配置的视觉模型；本地模式使用手动选择且安装完整的 Qwen3.5。两者都不可用或失败时自动回退系统 OCR。
- 图片翻译的目标语言可在结果面板直接切换（源语言固定为「自动识别」）；面板显示实际使用的目标语言。
- 自定义「图片」技能：在设置 → 划词行为 → 自定义技能中把类型切为「图片」，工具栏点击该技能后进入截图，框选后点击左上角的技能按钮对图片执行提示词。
- 图片理解：在线模式使用任意 OpenAI 兼容的视觉模型；本地模式需在设置 → 本地模型下载并手动选择 **Qwen3.5（翻译 / 通用 / 视觉）**，主文件和对应 mmproj-F16 投影器均须完整。未选择时会明确提示；切换选择后需重启本地引擎。

### 翻译提示词与单词查询提示词（schema 8）

翻译使用两套提示词，由算法自动切换，都放在设置 → 划词行为 → 工具栏技能 →「翻译」的编辑面板里：

- **翻译提示词**（`picker.prompts.translate`）：整句、段落等普通翻译使用，要求译入目标语言并只输出译文。
- **单词查询提示词**（`picker.prompts.wordLookup`）：自动识别到单个单词或短语时使用，要求输出词条（词头、音标或拼音、词性、义项、可选例句）。

判定是保守启发式：1–40 个拉丁字母的单词或 1–4 个汉字且不含常见句子标记的短词走单词查询，带空格、标点、URL、代码标识和更长文本走普通翻译。不需要手动选模式；想改词条格式直接改单词查询提示词。解释技能同样对候选词使用单词查询提示词，其余使用解释提示词。

图片技能里的「翻译」也提供同样的两个提示词（截图翻译提示词、截图单词查询提示词）：识别出的文字若是单个词或短语会自动走单词查询，否则走普通翻译。


### 默认输出与读音

默认翻译提示词要求整段译入目标语言、只输出译文并保留 Markdown/代码结构。默认单词提示词要求词条含词头、读音（英文 IPA、中文带声调拼音）、词性与最多 3 个常见义项，可带 1 个短例；`carzy` 等疑似错拼应先确认，未知词不编造释义或读音。解释通常 150–250 字，先用一句话概括，再给最多 3 个必要要点，简单内容更短；总结 3–5 点；润色只给结果；图片解释聚焦关键内容；OCR 只逐字转录。以上是默认提示词目标，自定义提示词和实际模型可能产生不同结果。

音标与拼音由模型生成，没有本地词典或第三方读音数据参与，因此可能不准确或缺失；不确定时以模型输出为准，必要时可自行核对。复制结果仅包含模型正文，朗读也只读正文。提示词遵循度随模型规模变化：0.8B 等小模型可能只做直译、忽略词条与目标语言规则，2B / 4B 明显更好。

默认任务输出预算为：解释/图片解释 512、总结 768 tokens，均不超过用户设置上限；翻译（含单词/短语）、润色、自定义提示词、自由追问、OCR 沿用用户上限。本地和在线规则一致，不改写用户配置。tokens 不等同于汉字数。

### 重复输出中止

流式输出会检测跨 chunk 的重复段落、列表项及周期重复，翻译单词时同样生效。检测到循环后取消请求、保留首份内容，并显示“检测到重复输出，已停止”。翻译/润色会参考原文中的合法重复；代码、表格、引用受保护，OCR 不做重复裁剪。该机制为保守启发式，可能漏检；提示词与自动化测试也不能保证真实模型的输出质量。
