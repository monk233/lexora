# 使用指南

## 安装与启动

LingoPick 是免安装应用：

1. 从 [Releases](https://github.com/monk233/lingopick/releases) 下载 `LingoPick-<version>-win-x64.zip`。
2. 解压到任意目录（建议不在 `Program Files` 等受限目录下，否则数据会写入 `%APPDATA%`）。
3. 双击 `lingopick.exe`。

首次启动会打开设置窗口；配置完成后关闭窗口，程序继续在系统托盘后台运行。右键/双击托盘图标可重新打开设置。要完全退出，使用设置页「退出程序」或托盘菜单「退出」。

> Windows 11 默认把新托盘图标收进「^」溢出区，可拖动到任务栏常驻。

## 配置翻译服务

### 在线 API

1. 设置 → 翻译服务 → 选择「在线 API」。
2. 选择预设（DeepSeek / OpenAI / Moonshot / 智谱 / Ollama / LM Studio / 自定义），或填写服务地址（以 `/v1` 结尾）与模型名。
3. 填入 API Key（本机 Ollama / LM Studio 可留空）。
4. 点「测试连接」，成功后即可使用。

### 本地模型（离线）

1. 设置 → 翻译服务 → 选择「本地模型」。
2. 点「下载引擎」（llama.cpp，约 23MB）并等待完成。
3. 在模型列表下载一个 GGUF（推荐 Qwen2.5 1.5B Instruct Q4_K_M，约 1.1GB），或「导入 GGUF」使用本机已有模型。
4. 选择模型后点「启动」，状态变为「运行中」。

完全离线环境可手动放置文件：

```
<程序目录>\data\engine\llama-server.exe（及同目录 DLL）
<程序目录>\data\models\*.gguf
```

放好后回到设置页刷新即可。

## 日常使用

1. 在任意应用中**拖动选中**一段文字，鼠标旁弹出工具栏。
2. 点击「翻译」：结果面板流式显示译文；可在面板顶部切换目标语言；「固定」可把结果留在桌面，点击「×」关闭。
3. 「总结」「解释」用简体中文处理选中文本。
4. 「朗读」用 Windows 系统语音朗读；「复制」复制原文。
5. 也可按快捷键 `Ctrl+Shift+D` 对当前选区唤起工具栏。

### 更多菜单

- **在此应用中禁用**：把当前应用加入黑名单（例如微信、游戏）。
- **划词设置…**：打开设置窗口。
- **禁用划词工具**：临时关闭划词功能，可在设置中重新启用。

## 设置说明

| 设置 | 说明 |
| --- | --- |
| 快捷键 | 全局唤起键，默认 `Ctrl+Shift+D`，可自行录制 |
| 技能 | 工具栏显示的按钮及顺序 |
| 紧凑模式 | 只显示图标，不显示文字 |
| 默认目标语言 | 「自动」时会中→英、其他语言→中文 |
| 应用黑名单 | 这些程序里不弹出工具栏 |
| 开机自启 | 登录 Windows 后自动在托盘启动；便携单文件版不支持 |
| 关闭窗口后驻留托盘 | 关闭设置窗口时保持后台运行（默认开） |

## 数据与隐私

- 配置文件、模型、日志都保存在程序目录 `data/`（不可写时使用 `%APPDATA%\LingoPick`）。
- 在线模式只把选中文本发送到你配置的服务地址；本地模式不联网。
- 日志不记录 API Key。
- 「关于」页可打开数据目录、查看版本与引擎状态。

## 故障排查

- **工具栏不出现**：确认划词已启用、未在「应用黑名单」中；部分应用（PDF 阅读器、管理员权限应用）不支持取词。
- **翻译报「服务未配置/Key 无效」**：检查在线服务地址是否以 `/v1` 结尾、API Key 是否正确，点「测试连接」查看具体错误。
- **本地模型启动失败**：确认 `data/engine/llama-server.exe` 存在、模型文件完整；日志在 `data/logs/llama.log`。
- **朗读无声音**：Windows 设置 → 时间和语言 → 语音，确认已安装语音包。
- **程序无法启动**：查看 `data/logs/main.log`；如果提示缺少 WebView2，请安装 Microsoft Edge WebView2 Runtime。
